## Air Mouse
Control your PC or Android TV from your phone.

### Setup
1. **Relay** — already deployed on Render (or self-host `relay/index.js`)
2. **PC Agent** — run `agent/run.bat` on Windows
3. **Mobile App** — open `mobile/` in Flutter, run on Android/iOS

### Requirements
- Flutter 3.x
- Python 3.8+ (for PC agent)
- Node.js 18+ (to self-host relay)
